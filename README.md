# آشنایی با هوش مصنوعی

این پروژه یک وب‌سایت آموزشی ساده برای آشنایی با هوش مصنوعی و مفاهیم مرتبط با آن است. این وب‌سایت با استفاده از HTML و بدون CSS طراحی شده و هدف آن تمرین مباحث مقدماتی HTML و ارائه‌ی اطلاعاتی درباره‌ی هوش مصنوعی است.

## صفحات و فایل‌های پروژه

- `index.html` — صفحه‌ی اصلی و معرفی موضوع
- `research.html` — صفحه‌ی پژوهش و توضیحات کامل‌تر درباره‌ی هوش مصنوعی
- `Image/AI.svg` — تصویر مفهومی هوش مصنوعی
- `Image/ollama.svg` — تصویر مربوط به Ollama و اجرای محلی مدل‌های هوش مصنوعی

## آموزش انتشار وب‌سایت با GitHub Pages

GitHub Pages سرویسی رایگان برای انتشار وب‌سایت‌های استاتیک، مانند پروژه‌های HTML، CSS و JavaScript است.

### مراحل انتشار

1. وارد [GitHub](https://github.com/) شوید یا یک حساب کاربری ایجاد کنید.
2. روی **New repository** کلیک کنید و یک مخزن جدید بسازید.
3. فایل‌های پروژه، از جمله `index.html` و پوشه‌های موردنیاز، را در مخزن بارگذاری کنید.
4. وارد بخش **Settings** مخزن شوید.
5. از منوی کناری، گزینه‌ی **Pages** را انتخاب کنید.
6. در قسمت **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کنید.
7. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب کنید و روی **Save** بزنید.
8. چند دقیقه صبر کنید تا وب‌سایت منتشر شود. سپس نشانی سایت را در همان بخش **Pages** مشاهده کنید.

### انتخاب نام مخزن

هنگام ساخت مخزن، می‌توانید نام دلخواهی انتخاب کنید؛ اما اگر می‌خواهید نشانی سایت به شکل `https://USERNAME.github.io` باشد، باید نام مخزن دقیقاً با نام کاربری GitHub شما مطابقت داشته باشد و به `.github.io` ختم شود.

برای مثال، اگر نام کاربری شما `Ali123` باشد، نام مخزن باید این باشد:

`Ali123.github.io`

در این حالت، نشانی سایت شما معمولاً به شکل زیر خواهد بود:

`https://Ali123.github.io`

**نکته:** به‌جای `Ali123` باید نام کاربری واقعی GitHub خودتان را قرار دهید. نام کاربری و نام مخزن به حروف بزرگ و کوچک حساس‌اند؛ بهتر است نام مخزن را دقیقاً مطابق نام کاربری خود وارد کنید.

اگر نام دیگری برای مخزن انتخاب کنید، باز هم می‌توانید با GitHub Pages سایت را منتشر کنید؛ اما نشانی آن معمولاً شامل نام مخزن نیز خواهد بود، مانند:

`https://USERNAME.github.io/REPOSITORY/`

### نکات مهم

- فایل `index.html` باید در پوشه‌ای قرار داشته باشد که برای انتشار انتخاب کرده‌اید.
- مسیر تصاویر و سایر فایل‌ها باید در کد HTML صحیح باشد.
- نام فایل‌ها و پوشه‌ها، از جمله حروف بزرگ و کوچک، باید دقیقاً مطابقت داشته باشد.
- GitHub Pages برای وب‌سایت‌های استاتیک مناسب است و به‌تنهایی کدهای سمت سرور مانند PHP را اجرا نمی‌کند.
- برای به‌روزرسانی سایت، تغییرات را در مخزن ذخیره کنید تا نسخه‌ی منتشرشده نیز به‌روزرسانی شود.

برای مطالعه‌ی راهنمای رسمی، به [مستندات GitHub Pages](https://docs.github.com/en/pages) مراجعه کنید.
